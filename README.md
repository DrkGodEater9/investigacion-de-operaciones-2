# Investigación de operaciones II: sitio de estudio

Sitio en React (Vite) con un menú por módulos y temas. Cada tema tiene Teoría, Paso a paso, Resuelve el tuyo y Práctica.
Hoy están hechos: 1.1 y 1.2 (las cuatro partes de cada uno), 3.1 (Teoría y Resuelve) y 3.2 (Resuelve); el resto está como esqueleto con su plan.

```bash
npm install
npm run dev     # desarrollo
npm run build   # genera dist/index.html (un solo archivo)
npm test        # verifica la lógica de la ruta crítica
```

La estructura, el diseño y cómo agregar un tema están en **GUIA_DEL_PROYECTO.md**.
